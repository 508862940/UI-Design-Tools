# UI设计工具集

🎨 **专业的在线UI设计平台** - 无需安装，打开即用的设计工具集合

## 📋 项目概述

这是一个集成了多种UI设计工具的在线平台，为设计师和开发者提供一站式的界面设计解决方案。

## 🛠️ 工具集合

### 1. CSS样式生成器
- **渐变生成器** - 创建线性和径向渐变效果
- **阴影生成器** - 生成各种阴影效果
- **动画生成器** - 创建CSS动画
- **按钮生成器** - 定制按钮样式
- **边框生成器** - 创建边框样式

### 2. 图标设计工具
- **SVG编辑器** - 专业的矢量图标编辑
- **预设模板** - 丰富的图标模板库
- **多格式导出** - 支持SVG、PNG等格式
- **图层管理** - 完整的绘图工具集

### 3. UI组件设计器 ⭐
- **拖放编辑** - 基于GrapesJS的可视化编辑器
- **组件库** - 丰富的预设UI组件
- **响应式设计** - 支持桌面、平板、手机视图
- **代码导出** - 生成HTML/CSS/JS代码
- **实时预览** - 所见即所得的设计体验

## 🌟 特色功能

- ✨ **零门槛使用** - 无需注册，打开即用
- 🎯 **中文友好** - 完整中文界面和文档
- 📱 **响应式设计** - 完美适配各种设备
- 💻 **代码导向** - 实时生成可用代码

- ☁️ **云端访问** - 随时随地在线使用

## 🚀 快速开始

### 本地运行
1. 下载项目文件
2. 使用HTTP服务器运行：
   ```bash
   # 使用Python
   python -m http.server 8080

   # 使用Node.js
   npx serve .

   # 使用PHP
   php -S localhost:8080
   ```
3. 访问 `http://localhost:8080`

### 在线部署

推荐使用以下平台部署：

#### Netlify（推荐）
1. 注册 [Netlify](https://netlify.com) 账号
2. 拖拽项目文件夹到部署区域
3. 等待部署完成，获得访问链接

#### GitHub Pages
1. 将代码上传到GitHub仓库
2. 在仓库设置中启用GitHub Pages
3. 选择主分支作为发布源

#### Vercel
1. 注册 [Vercel](https://vercel.com) 账号
2. 连接GitHub仓库或直接上传
3. 自动部署并获得访问链接
